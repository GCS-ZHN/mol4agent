has a deterministic gzip sibling (same name plus `.gz`) for adapter tests.

|---|---|

| 1crn.ent | pdb alias |
| 1crn.pdbqt | pdbqt |
| 1crn.pqr | pqr |
| 1crn.cif / 1crn.mmcif / 1crn.mcif | mmcif aliases |
| 1crn.bcif | bcif |
| aspirin.mol | mol |
| aspirin.sdf / aspirin.sd | sdf aliases |
| water.mol2 | mol2 |
| water.xyz | xyz |
